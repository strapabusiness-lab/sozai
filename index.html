The default endpoint is unavatar.io, a free public avatar lookup that resolves a TikTok handle to that account's real picture. It is rate limited and it can't see private or non-existent accounts, so anything it can't resolve falls back to the coloured initial. Point this field at your own proxy (or an Apify/TikTok integration that returns an image) for higher limits — it just has to return an image for {username}.
TikTok live event ingestion still requires a supported TikTok integration/API on the deployed server. The auction engine itself works locally without one.
